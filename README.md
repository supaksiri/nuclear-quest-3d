# Nuclear Quest 3D

เว็บแอป 3D Interactive ภาษาไทย สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 4 เรียนรู้เรื่องกัมมันตรังสีผ่านแบบจำลอง การทดลองเสมือน และภารกิจสะสมคะแนน

## เนื้อหาและฟีเจอร์

1. ห้องทดลองรังสีแอลฟา บีตา และแกมมา
2. ทดลองวัสดุกำบัง: ไม่กั้น กระดาษ อะลูมิเนียม และตะกั่ว
3. เครื่องตรวจรังสีเสมือนและค่า CPM จำลอง
4. เครื่องคำนวณครึ่งชีวิตของ C-14, I-131, Co-60, Cs-137 และ P-32
5. กราฟการสลายตัวและโจทย์ครึ่งชีวิตแบบสุ่ม
6. การสลายแอลฟา บีตาลบ บีตาบวก แกมมา และการจับอิเล็กตรอน
7. แบบจำลอง Nuclear Fission และ Nuclear Fusion
8. การใช้ประโยชน์ของไอโซโทปทางการแพทย์ เกษตร อุตสาหกรรม และโบราณคดี
9. การจำลองหลักความปลอดภัย เวลา–ระยะทาง–วัสดุกำบัง
10. ภารกิจสรุป คะแนน ความก้าวหน้า และใบประกาศ
11. บันทึกชื่อ คะแนน และความก้าวหน้าด้วย LocalStorage
12. Responsive รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript ES Modules
- Three.js และ OrbitControls ผ่าน CDN
- Canvas API สำหรับกราฟ
- LocalStorage สำหรับบันทึกผลในอุปกรณ์

## เปิดใช้งานผ่าน GitHub Pages

1. Merge Pull Request เข้า branch `main`
2. เปิด `Settings > Pages`
3. เลือก `Deploy from a branch`
4. เลือก branch `main` และโฟลเดอร์ `/root`
5. กด Save

เว็บไซต์จะอยู่ที่ `https://supaksiri.github.io/nuclear-quest-3d/`

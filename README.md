# Nuclear Quest 3D

เว็บแอป 3D Interactive สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 4 เพื่อเรียนรู้เรื่องกัมมันตรังสี การแผ่รังสี วัสดุกำบัง และครึ่งชีวิต

## ฟีเจอร์เวอร์ชันแรก

- แบบจำลองนิวเคลียส 3D
- การจำลองรังสีแอลฟา บีตา และแกมมา
- ทดลองวัสดุกำบัง: กระดาษ อะลูมิเนียม และตะกั่ว
- เครื่องจำลองครึ่งชีวิตพร้อมกราฟ
- รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดใช้งาน

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ หรือเปิดใช้งาน GitHub Pages จาก branch `main`

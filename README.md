# Nuclear Quest 3D

เว็บแอป 3D Interactive ภาษาไทย สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 4 เรียนรู้เรื่องกัมมันตรังสีผ่านแบบจำลอง การทดลองเสมือน เนื้อหาเชิงลึก และภารกิจสะสมคะแนน

**สถานะ:** Complete Classroom Edition 1.1 — Detailed Learning Content

## เมนูการเรียนรู้

1. **การแผ่รังสี** — สาเหตุการสลาย สมบัติ α, β, γ อำนาจก่อไอออน อำนาจทะลุผ่าน วัสดุกำบัง และค่า CPM จำลอง
2. **ครึ่งชีวิต** — ความหมาย สูตรคำนวณ กราฟ ไอโซโทปหลายชนิด ตัวอย่างพร้อมวิธีคิด และโจทย์สุ่ม
3. **สมการนิวเคลียร์** — สัญลักษณ์นิวเคลียร์ การอนุรักษ์เลขมวลและเลขอะตอม α, β⁻, β⁺, γ และ electron capture
4. **ฟิชชัน–ฟิวชัน** — ปฏิกิริยาลูกโซ่ มวลวิกฤต มวลพร่อง E = mc² เงื่อนไข ผลิตภัณฑ์ และการใช้งาน
5. **การใช้ประโยชน์** — การแพทย์ เกษตร อาหาร อุตสาหกรรม โบราณคดี และเกมจับคู่ไอโซโทป
6. **ความปลอดภัย** — หลัก ALARA เวลา ระยะทาง วัสดุกำบัง การปนเปื้อน และสถานการณ์ฉุกเฉิน
7. **ภารกิจสรุป** — คำถามจากทุกบท คะแนน ความก้าวหน้า อภิธานศัพท์ และใบประกาศ

## ฟีเจอร์

- ฉาก 3D ด้วย Three.js และ OrbitControls
- ปรับชนิดรังสีและวัสดุกำบังแบบ Interactive
- เครื่องตรวจรังสีและค่า CPM จำลอง
- เครื่องคำนวณครึ่งชีวิตพร้อมกราฟ Canvas
- แบบจำลองฟิชชันและฟิวชัน
- แบบฝึกหัดสุ่มพร้อม Feedback
- บันทึกชื่อ คะแนน และความก้าวหน้าด้วย LocalStorage
- ใบประกาศพิมพ์ได้
- Responsive รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์
- มี `TEACHER_GUIDE.md` สำหรับแผนใช้ในชั้นเรียน คำถามอภิปราย และแนวทางประเมิน

## เปิดใช้งานผ่าน GitHub Pages

1. Merge Pull Request เข้า branch `main`
2. เปิด `Settings > Pages`
3. เลือก `Deploy from a branch`
4. เลือก branch `main` และโฟลเดอร์ `/root`
5. กด Save

เว็บไซต์จะอยู่ที่ `https://supaksiri.github.io/nuclear-quest-3d/`
